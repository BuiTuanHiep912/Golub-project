## Người nhận cần biết

- Thứ tự chạy: `make data` → `make ingest` → `make warehouse` (Windows: `python run_all.py data ingest warehouse`).
  Chưa chạy `make ingest` thì kho vẫn dựng được (tính lô tại chỗ) nhưng không có `log_ingest`.
- Truy vấn:

```python
from src.warehouse import connect
con = connect()   # read_only, nhiều người đọc cùng lúc được
df = con.sql("""
    SELECT s.class, s.source, avg(f.value_log10) AS mean_log10
    FROM fact_expression f JOIN dim_sample s USING (sample_id)
    WHERE f.probe_id = 'M23197_at'          -- CD33
    GROUP BY ALL
""").df()
```

- `batch_id` theo TV2: `B1-DFCI`, `B2-CALGB`, `B3-St-Jude`, `B4-CCG`. `fact_qc` nối `dim_sample` qua `(sample_id, batch_id)`.
- `value_raw` là giá trị MAS4 gốc (có âm), `value_log10` là giá trị đã threshold + log10; phân tích dùng `value_log10`.
- Chỉ 38 mẫu `split = 'train'` là dữ liệu tham chiếu; tính tham số thì lọc `WHERE split = 'train'`.
- Đang mở dashboard có giữ kết nối thì `make warehouse` trên Windows có thể báo file đang bị khóa: tắt app rồi chạy lại.
