# Ghi chú bàn giao — Công việc 2.4: Nhập theo lô, chất lượng; khung đánh giá và thí nghiệm selection bias

Phụ trách: TV2 · Kế hoạch mục 5.3 (2.4), lịch giai đoạn 2 (ADR-014) · ADR-013, ADR-030, ADR-031

## Đã làm gì

- **`src/evaluate.py`** (đã merge vào `main`): `evaluate(pipeline, X, y, scheme)` với 4 sơ đồ
  `original_split`, `loocv`, `nested_cv` (có vòng trong khi truyền `param_grid`), `wrong_cv`; balanced
  accuracy, AUC, sensitivity/specificity, khoảng tin cậy Wilson; `mcnemar_test()` ghép hai mô hình theo
  `sample_id`; `confusion_counts()` giữ cột `uncertain` (ADR-013). Thí nghiệm selection bias:
  `selection_bias_experiment()` 100 lần hoán vị × {CV đúng, CV sai}.
- **`src/ingest.py`** (đã merge vào `main`): `ingest_batches()` chia 72 mẫu thành 4 lô theo phòng lab, chặn
  lô vi phạm ràng buộc, ghi bảng chất lượng; `validate_new_sample(path)` kiểm tra file chip của bệnh nhân
  mới; `sample_quality()`. Quy tắc gắn cờ theo mẫu tách thành `quality.sample_qc()` dùng chung (ADR-030).
- **Nhánh `2.4-f8-f10-demo-v2`** (chưa merge): bộ 13 file lỗi mẫu (`python -m src.ingest --demo`); F8
  "Chất lượng dữ liệu theo lô" (`src/viz_ingest.py`); F10 bản cuối trên tầng curated qua `make_preprocess()`
  của TV3; mọi bước học của `make evaluate` chỉ dùng 38 mẫu train (ADR-031).
- **Báo cáo** (nhánh `2.4-report-draft-v2` và nhánh này): nháp mục 3.5 (đánh giá, H3), nháp mục 2.8 (nhập
  theo lô); rà soát rò rỉ dữ liệu code TV1, TV3, TV4 (`docs/leakage_review.md`); ghi chú bàn giao này.
- **Nghiệm thu** (12/11/2026, môi trường Python 3.11 đúng phiên bản `environment.yml`): `pytest tests/` =
  83 passed (`2.4-evaluate`) → 103 (`2.4-ingest-v2`) → 108 (`2.4-f8-f10-demo-v2`); notebook
  `08_evaluation` và `TV2_tong_quan_cong_viec` chạy lại không lỗi. Chưa chạy lại sau khi merge vào `main`.

## Người nhận cần biết

- Lệnh (máy không có `make` thì dùng `python -m src.<module>`):

```bash
make data && make ingest          # tầng raw → curated; 4 lô, ghi batches/qc_samples/ingest_log
python -m src.ingest --demo       # 13 file demo trong data/demo/, kèm README kết quả mong đợi
python -m src.viz_ingest          # F8
make evaluate                     # 4 sơ đồ + 100 hoán vị, khoảng 6 phút → summary_*.csv, F10, F11
```

- **TV1** đánh giá weighted voting bằng đúng khung chung. Đưa nguyên bộ phân loại vào để bước chọn gen được
  fit lại ở mỗi fold:

```python
from src.evaluate import evaluate, plot_roc_cm
from src.golub_wv import GolubWeightedVoting
from src.load import load_golub

X, s = load_golub("curated")                     # X_log10, chỉ mục sample_id
res = evaluate(GolubWeightedVoting(), X, s["class"], "original_split", split=s["split"])
res["per_fold"]       # chỉ số + Wilson; "uncertain" tính là sai, kèm số dự đoán uncertain
res["predictions"]    # khóa thứ 6 (ADR-008): y_true, y_pred, score theo sample_id
```

- **TV1, TV6:** `validate_new_sample(path)["values"]` ở **thang MAS4 gốc**. Phải gọi
  `src.preprocess.threshold_log10()` trước khi đưa vào mô hình học trên `X_log10`.
- **TV3:** đọc bảng chất lượng qua hằng `BATCHES_FILE`, `QC_FILE` trong `src/ingest.py`, hoặc gọi
  `ingest_batches()` (mặc định không ghi file). Xem lưu ý `batch_id` ở trên.
- **TV6:** `ingest_batches(extra_files=[...])` nhận thêm lô từ file CSV để demo lô bị chặn; lỗi của lô thêm
  không làm đổi trạng thái 4 lô thật.
