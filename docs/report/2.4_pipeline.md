# 2.4. Quy trình xử lý dữ liệu (pipeline) (TV2 – công việc 1.1)

> Theo `Makefile` và `run_all.py` trên `main` ngày 18/11/2026. Máy không có `make` (Windows) thì dùng
> `python run_all.py <bước>`, các bước giống hệt.

Mỗi bước là một module Python chạy được độc lập (`python -m src.<module>`) và chỉ đọc đầu ra của bước trước
(mục 2.2). Lệnh `make data` nối các bước của giai đoạn 1 thành một chuỗi:

```
make fetch      raw/ (tải, đối chiếu MD5)
make data   =   standardize → quality → curate → test
                raw/ → standardized/ → cleansed/ → curated/ → pytest
```

| Bước | Lệnh | Script / hàm chính | Đầu vào → Đầu ra | Phụ trách |
|---|---|---|---|---|
| 0. Tải dữ liệu gốc | `make fetch` | `src/fetch.py`: `fetch()` | Kaggle (gói zip), OpenIntro → `raw/`; file đã có và đúng MD5 thì bỏ qua | TV2 |
| 1. Nạp và ghép | `make standardize` | `src/load.py`: `build()` | `raw/` → `standardized/` (4 file Parquet) | TV2 |
| 2. Kiểm tra chất lượng | `make quality` | `src/quality.py`: `run_quality()` | `standardized/` → `cleansed/` + `quality_report.md` | TV2 |
| 3. Tiền xử lý | `make curate` | `src/preprocess.py` | `cleansed/` → `curated/` | TV3 |
| 4. Kiểm thử | `make test` | `python -m pytest tests/` | Bảng 2.4, chống rò rỉ, giao diện dùng chung, test từng công việc | cả nhóm |
| Cả chuỗi | `make data` | bước 1–4 | `raw/` → `curated/`, khoảng 1 phút | |

*Bảng 2.8. Pipeline dữ liệu của giai đoạn 1.*

**Dừng ngay khi có lỗi.** Chuỗi không chạy tiếp trên dữ liệu chưa đạt:

- `fetch()`: MD5 của file vừa tải lệch với `SOURCES.md` thì xóa file đó và báo lỗi, không để file sai nằm trong
  tầng raw.
- `build()`: tập mã giữa các nguồn lệch, ghép sai hoặc kích thước sai thì ném `ValueError` kèm mã mẫu, không
  ghi tầng standardized (mục 2.1.2).
- `run_quality()`: có kiểm tra `[FAIL]` thì vẫn ghi `quality_report.md` để xem lý do, nhưng xóa bản cũ của tầng
  cleansed và thoát mã 1, nên `make` dừng trước bước 3 (ADR-006).
- Bước nào cũng báo lệnh cần chạy nếu tầng trước chưa có.
- `tests/test_load.py` báo lỗi (không bỏ qua) khi chưa có dữ liệu, nên `make test` không thể xanh mà không
  kiểm gì.

**Các bước thêm ở giai đoạn 2** (ADR-014) dùng chung cách tổ chức trên:

| Lệnh | Script | Đầu vào → Đầu ra | Phụ trách |
|---|---|---|---|
| `make ingest` | `src/ingest.py` | `standardized/` → `cleansed/batches.parquet`, `qc_samples.parquet`, `ingest_log.csv` (mục 2.8) | TV2 |
| `make warehouse` | `src/warehouse.py` | `cleansed/` + `curated/` → `data/warehouse/golub.duckdb` | TV3 |
| `make evaluate` | `src/evaluate.py` | `curated/` → `results/metrics/summary_*.csv`, hình F10, F11 (mục 3.5), khoảng 6 phút | TV2 |
| `make figures` | `src/viz.py` | các tầng → `results/figures/` | TV6 |
| `make app` | `app/Home.py` | dashboard Streamlit | TV6 |
| `make all` | | `data` → `ingest` → `warehouse` → `evaluate` → `figures` | |

Chạy lại từ đầu trên máy mới: `make fetch data` rồi `make all` (Windows: `python run_all.py fetch data`, rồi
`python run_all.py all`).
